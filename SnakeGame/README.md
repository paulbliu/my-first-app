# Snake Game

A classic Snake game built with Python and Pygame.

## Setup

1. Activate the virtual environment:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`

2. The required dependencies (pygame) are already installed in the virtual environment.

## How to Play

Run the game:
```bash
python snake_game.py
```

## Controls

### Start Menu
- Click the START GAME button or press SPACE/ENTER to begin

### During Gameplay
- Arrow Keys: Control the snake's direction
  - UP: Move up
  - DOWN: Move down
  - LEFT: Move left
  - RIGHT: Move right
- P or ESC: Pause the game
- Q (while paused): Quit to desktop

### Game Over Screen
- Click the RESTART button to play again
- Press SPACE or ENTER to restart

## Rules

- Eat the red food to grow and increase your score
- Don't hit the walls or your own body
- The game ends when you collide with a wall or yourself

## Features

- Start menu with animated button
- Pause functionality (P or ESC key)
- Classic snake gameplay
- Score tracking
- Collision detection
- Food spawning system
- Game over screen with final score display
- Restart button with hover effect
- Keyboard shortcuts for quick navigation
